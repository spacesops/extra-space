# Extra space

A single-page site answering “What should you do with extra space?”

Everything lives in `index.html`. There are no external fonts, images, or scripts.

## View

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```

Then go to [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
